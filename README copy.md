# Boarding Buddy — React dashboard

React + JSX conversion of the Member 4 Boarding Buddy favourites, messaging, and reviews dashboard. Built with Vite.

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. To create a production build, run `npm run build`.

## Included functionality
- Navigate between Favourites, Messaging, and Reviews & Ratings.
- Search saved properties and remove favourites.
- Browse demo conversations, switch contacts, send messages, and start enquiries.
- Sort reviews, mark reviews helpful, and submit a review with validation.
- Responsive layout styled to closely match the supplied original dashboard.

## Demo limitations
This is a frontend prototype. Data is kept in React state and resets when the page reloads. Messages and reviews are not sent to a backend. Connect an API/database and authentication for production use.
